## ECE 3300 - Introduction to Digital Circuit Design using Verilog

# Overview
- This repository contains lab projects completed for Introduction to Digital Circuit Design using Verilog. The course focuses on designing and simulating digital systems using Verilog HDL.

# Technology Used
- Verilog Hardware Description Language
- Digital logic design principles
- Circuit simulation tools (Vivado)

# Repository Structure
Each folder contains a specific lab assignment, including:
- Verilog source files (.v)
- Constraint files (.xdc)
- Simulation files
